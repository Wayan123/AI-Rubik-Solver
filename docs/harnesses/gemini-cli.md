# Gemini CLI

Official project: https://github.com/google-gemini/gemini-cli. Evidence checked 2026-09-30.

Rubik Arena detects the `gemini` binary and version only. It remains catalog-only until a stable passive model-list contract and a no-tools headless benchmark invocation are verified with sanitized fixtures and side-effect tests.

Authenticate and update through Google's official instructions. Discovery does not read API keys, `GEMINI.md`, workspace context, or account state, and does not send a Gemini request.
