# Aider

Official project: https://github.com/Aider-AI/aider and https://aider.chat. Evidence checked 2026-09-30.

Rubik Arena detects the `aider` binary and version only. Although Aider documents model listing and message modes, this project keeps it catalog-only until file edits, Git behavior, shell execution, prompts, output parsing, and cancellation are isolated and fixture-tested.

Rubik Arena does not read `.env`, Aider credentials, or model settings. `--yes-always` and equivalent blanket approval are forbidden for a future adapter.
